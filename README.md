# AMS Count · ระบบตรวจนับทรัพย์สิน

เว็บบนคอม + แอป APK บนเครื่องยิง CipherLab ใช้ฐานข้อมูล Supabase ร่วมกัน ข้อมูลซิงก์สดทุกเครื่อง
เน็ตหลุดก็นับต่อได้ และส่งไฟล์ผ่านสาย USB ได้ถ้าไม่มีเน็ตเลย

```
 คอม (เว็บ)  ──เน็ต──▶  Supabase (ฐานข้อมูล)  ◀──เน็ต──  เครื่องยิง (แอป APK)
```

ทำครั้งเดียวประมาณ 30–45 นาที ทุกบริการใช้แพ็กเกจฟรี

| ขั้น | ทำที่ | ได้อะไร |
|---|---|---|
| 1 | supabase.com | ฐานข้อมูล |
| 2 | github.com | ที่เก็บโค้ด + ระบบ build แอปอัตโนมัติ + เว็บไซต์ |
| 3 | GitHub Secrets | กุญแจเซ็นแอป (ทำให้อัปเดตแอปทับได้) |
| 4 | เว็บไซต์ของคุณ | บัญชี Admin + ทีม |
| 5 | เครื่องยิง | ติดตั้งแอป |

---

## ขั้นที่ 1 · สร้างฐานข้อมูล Supabase

1. ไปที่ **supabase.com** → Start your project → สมัครด้วย Gmail
2. **New project**
   - Name: `ams-count`
   - Database Password: ตั้งรหัสยาว ๆ แล้วจดเก็บไว้ (ระบบนี้ไม่ได้ใช้ แต่ Supabase บังคับให้ตั้ง)
   - Region: **Southeast Asia (Singapore)** เร็วที่สุดสำหรับไทย
   - กด Create แล้วรอประมาณ 2 นาที
3. เมนูซ้าย **SQL Editor** → **New query** → เปิดไฟล์ `supabase/schema.sql` ก๊อปทั้งไฟล์มาวาง → กด **Run**
   - ต้องขึ้นว่า `Success. No rows returned`
4. เมนูซ้าย **Authentication** → **Sign In / Providers** → **Email**
   - ปิด **Confirm email** (ระบบใช้รหัสพนักงาน + PIN ไม่มีการส่งอีเมล)
   - เปิด **Enable Email provider** ค้างไว้ และเปิด **Allow new users to sign up** ค้างไว้ (Admin ใช้ตอนเพิ่มคนในทีม)
   - กด Save
5. เมนูซ้าย **Project Settings** → **API** แล้วจดค่า 2 อย่าง
   - **Project URL** เช่น `https://abcdxyz.supabase.co`
   - **anon public key** (ตัวยาว ๆ ขึ้นต้น `eyJ…`) หรือ **Publishable key** (`sb_publishable_…`)
   - ⚠️ ห้ามใช้ **service_role key** เด็ดขาด ตัวนั้นเป็นกุญแจใหญ่ เก็บไว้กับคุณคนเดียว

## ขั้นที่ 2 · เอาโค้ดขึ้น GitHub (ได้ทั้งเว็บและแอป)

1. สมัคร **github.com** (ใช้ Gmail เดิมได้)
2. มุมขวาบน **+** → **New repository**
   - Repository name: `ams-count`
   - เลือก **Public** (GitHub Pages ฟรีเฉพาะ repo สาธารณะ อ่านเรื่องความปลอดภัยท้ายคู่มือ)
   - กด Create repository
3. ในหน้า repo กด **uploading an existing file** → ลาก **ทุกอย่างในโฟลเดอร์นี้** ไปวาง (โฟลเดอร์ `web`, `android`, `supabase`, `.github` และไฟล์ README.md) → **Commit changes**
   - ตรวจว่ามีโฟลเดอร์ `.github/workflows` ขึ้นใน repo ถ้าไม่มี (Windows อาจซ่อนโฟลเดอร์ที่ขึ้นต้นด้วยจุด) ให้กด **Add file → Create new file** แล้วพิมพ์ชื่อ `.github/workflows/build-and-publish.yml` จากนั้นก๊อปเนื้อไฟล์มาวาง แล้วกด Commit
4. ค่าการเชื่อมต่อใส่ไว้ใน `web/config.js` ให้แล้ว (โปรเจกต์ `yggcnezlwdzcveldyxcp`) ไม่ต้องแก้ ถ้าวันหลังเปลี่ยนโปรเจกต์ Supabase ค่อยแก้ไฟล์นี้
5. **Settings** → **Pages** → Source: เลือก **GitHub Actions**

## ขั้นที่ 3 · ใส่กุญแจเซ็นแอป (ทำครั้งเดียว)

กุญแจอยู่ในไฟล์แยกที่ได้รับ (`AMS-Count-กุญแจเซ็นแอป-เก็บเป็นความลับ.zip`)

1. ใน repo: **Settings** → **Secrets and variables** → **Actions** → **New repository secret**
2. เพิ่ม 2 ค่า
   - Name `AMS_KEYSTORE_BASE64` → Secret: ก๊อปเนื้อไฟล์ `keystore-base64.txt` ทั้งหมด
   - Name `AMS_KEYSTORE_PASSWORD` → Secret: ก๊อปเนื้อไฟล์ `password.txt`
3. แท็บ **Actions** → เลือก **Build APK + Publish web** → **Run workflow**
4. รอประมาณ 5–8 นาทีจนขึ้นเครื่องหมายถูกสีเขียว แล้วคุณจะได้
   - **เว็บไซต์**: `https://<ชื่อ GitHub>.github.io/ams-count/`
   - **หน้าติดตั้งแอป**: `https://<ชื่อ GitHub>.github.io/ams-count/install.html`
   - **ไฟล์ APK**: `https://<ชื่อ GitHub>.github.io/ams-count/download/ams-count.apk`

⚠️ **เก็บไฟล์กุญแจไว้ให้ดี** (เช่นใน Google Drive ส่วนตัว) ถ้าหาย แอปเวอร์ชันใหม่จะติดตั้งทับของเดิมไม่ได้ ต้องถอนแอปเก่าออกก่อน ซึ่งผลนับที่ยังไม่ได้ส่งจะหายไปด้วย

## ขั้นที่ 4 · เริ่มใช้บนคอม

1. เปิดเว็บไซต์จากขั้นที่ 3
2. ครั้งแรกระบบจะขึ้น **สร้างบัญชี Admin** → ใส่ชื่อ รหัสพนักงาน และ PIN 4–8 หลัก
   (บัญชีแรกเป็น Admin อัตโนมัติ คนต่อไปต้องให้ Admin เพิ่ม)
3. เมนู **ทีม + ตั้งค่า** → เพิ่มคนนับ ใส่ชื่อ รหัสพนักงาน PIN เริ่มต้น และบทบาท
4. เมนู **รอบนับ** → สร้างรอบนับใหม่ → ① นำเข้าไฟล์ Excel (ไฟล์ SAP เดิมใช้ได้เลย) → มอบพื้นที่ → **ปล่อยภารกิจ**

## ขั้นที่ 5 · ติดตั้งแอปบนเครื่องยิง CipherLab

1. เปิด **หน้าติดตั้งแอป** ใน Chrome บนเครื่องยิง ทางลัดคือเอาเครื่องยิงยิง QR ในเมนู ทีม + ตั้งค่า บนคอม
2. กดดาวน์โหลด แล้วแตะไฟล์ `ams-count.apk`
3. ถ้าเครื่องถาม **อนุญาตให้ติดตั้งจากแหล่งนี้** ให้เปิดอนุญาต · ถ้ามีคำเตือนจาก **Play Protect** ให้กด **ติดตั้งต่อ**
4. ตั้งค่าเครื่องยิง: **ReaderConfig** → Output → **Keyboard Emulation** · Suffix = **Enter** · Symbology: เปิด **QR Code** และ **Code 128**
5. เปิดแอป AMS Count → เข้าสู่ระบบด้วยรหัสพนักงาน + PIN → เลือกพื้นที่ → กดปุ่ม **สแกน** แล้วยิงได้เลย

**ยิงแล้วมีเสียงบี๊บแต่รหัสไม่ขึ้น:** แอป AMS เดิมเปิดค้างอยู่และแย่งหัวอ่าน ให้ปัดแอปเดิมทิ้งจากหน้าแอปที่เปิดค้าง เมื่อเลิกใช้ระบบเดิมแล้วควรถอนแอปเดิมออก

ไม่มีเน็ตบนเครื่องยิง: ดาวน์โหลด APK บนคอม → ต่อสาย USB → ก๊อปไปไว้ใน `Download` ของเครื่องยิง → เปิดแอป **Files** บนเครื่องยิงแล้วแตะไฟล์

## การใช้งานประจำ

| งาน | ที่ไหน |
|---|---|
| ดูผลสด แผนที่พื้นที่ | คอม → ② นับ |
| ตัดสินย้ายแผนก / ของไม่อยู่ในทะเบียน / ของชำรุด | คอม → ③ ตรวจ |
| ปิดรอบ + Excel / Transfer AS02 / Write-Off ABAVN | คอม → ④⑤ ปิด + ส่งออก |
| พิมพ์สติ๊กเกอร์ QR | คอม → พิมพ์สติ๊กเกอร์ |
| เครื่องยิงไม่มีเน็ต | คอม → สาย USB · เครื่องยิง → ฉัน → สาย USB |
| ลืม PIN / ปิดบัญชีคนลาออก | คอม → ทีม + ตั้งค่า |

**เน็ตหลุด** นับต่อได้ตามปกติ แถบด้านบนจะขึ้น "รอส่ง N" แล้วส่งเองเมื่อเน็ตกลับมา
อยากมั่นใจว่าข้อมูลถึงระบบครบ ให้กด **ฉัน → ส่ง + ตรวจครบ**

**ไฟล์ที่แอปบันทึก** อยู่ที่ `Download/AMS Count` ในเครื่องยิง ต่อสาย USB แล้วเปิดดูจากคอมได้

## อัปเดตเวอร์ชัน

แก้ไฟล์ใน GitHub (หรือให้ผู้พัฒนาส่งไฟล์ใหม่มาอัปโหลดทับ) → ระบบ build ให้เองภายใน 5–8 นาที

- **เว็บ:** อัปเดตทันที กดรีเฟรชหน้า
- **แอป:** เปิดหน้าติดตั้งแอปบนเครื่องยิง แล้วดาวน์โหลดติดตั้งทับ ผลนับในเครื่องไม่หาย
- เลขเวอร์ชันดูได้ที่ แอป → ฉัน → เกี่ยวกับ

## ข้อควรรู้

- **Supabase ฟรี:** ถ้าไม่มีใครใช้เกิน 7 วัน โปรเจกต์จะถูกพักไว้ ข้อมูลไม่หาย ก่อนเริ่มรอบใหม่ให้เข้า supabase.com แล้วกด **Restore project** รอ 2–3 นาที (หรืออัปเกรด Pro เดือนละ 25 ดอลลาร์ถ้าไม่อยากให้พัก)
- **ความจุ:** ฟรี 500 MB · ทะเบียน 1,791 รหัสบวกผลนับหนึ่งรอบใช้ไม่ถึง 5 MB
- **WebView ของเครื่อง:** แอปต้องใช้ Android System WebView เวอร์ชัน 90 ขึ้นไป ถ้าเก่ากว่า แอปจะเตือนตอนเปิด ให้อัปเดตจาก Play Store หรือจากเว็บไซต์ CipherLab
- **ไฟร์วอลล์บริษัท:** ถ้า Wi-Fi บล็อกเว็บภายนอก ให้ IT อนุญาต `*.supabase.co` และ `*.github.io` ผ่านพอร์ต 443

## ความปลอดภัย

- repo แบบ Public ทำให้คนภายนอกเห็นโค้ดและ anon key ได้ แต่ **อ่านหรือแก้ข้อมูลไม่ได้** เพราะฐานข้อมูลล็อกด้วยสิทธิ์ (Row Level Security)
  - ต้องเข้าสู่ระบบด้วยบัญชีที่ Admin เปิดใช้แล้วเท่านั้น
  - คนนับส่งผลนับได้อย่างเดียว
  - นำเข้าทะเบียน อนุมัติ และปิดรอบ ทำได้เฉพาะ Admin
  - ใครสมัครบัญชีเองจะถูกปิดใช้ไว้จนกว่า Admin จะเปิดให้
- ถ้าไม่อยากให้โค้ดเป็นสาธารณะ ใช้ repo แบบ Private แล้วฝากเว็บที่ **Cloudflare Pages** แทน (ฟรี เชื่อมกับ repo Private ได้) หรืออัปเกรด GitHub Pro
- PIN เป็นตัวเลขสั้น ๆ เพื่อให้ใช้บนเครื่องยิงง่าย ให้ตั้ง PIN ที่ไม่ใช่วันเกิด และปิดบัญชีคนที่ลาออกทันที

### สำหรับผู้พัฒนา

```
web/            หน้าเว็บ = หน้าแอป (ชุดเดียวกัน)
  index.html    หน้าจอทั้งหมด (คอม + เครื่องยิง)
  store.js      ตัวเชื่อม Supabase (kv / events / realtime / auth) + บันทึกไฟล์ผ่าน Android
  config.js     URL + anon key
  install.html  หน้าติดตั้งแอป
  lib/ fonts/   ไลบรารีและฟอนต์ในเครื่อง (ใช้ได้ไม่ต้องมีเน็ต)
android/        แอป Android (WebView + WebViewAssetLoader) · gradle คัดลอก web/ เข้า assets/www ตอน build
supabase/       schema.sql (ตาราง + RLS + realtime + ฟังก์ชัน)
.github/        build APK (เซ็นด้วยกุญแจจาก Secrets) + เผยแพร่เว็บขึ้น GitHub Pages
```

- **ข้อมูล:** `kv` เก็บ `meta/round` (รอบนับ พื้นที่ ทีม) กับ `master/cN` (ทะเบียนแบ่งก้อน) · `events` เก็บ 1 แถวต่อ 1 เหตุการณ์ (`scan` / `edit` / `del` / `rv`) ใช้ id จากเครื่องเป็น primary key จึงส่งซ้ำไม่ซ้ำ
- **การคำนวณผลนับ:** ทุกเครื่องรวมเหตุการณ์เรียงตามเวลา คนที่สแกนก่อนได้นับ การแก้ไขล่าสุดเป็นค่าที่ใช้
- **บัญชีผู้ใช้:** อีเมลสมมุติ `<รหัสพนักงาน>@ams-count.example.com` · รหัสผ่าน `AMS-<PIN>-<รหัสพนักงาน>`
- **build เองในเครื่อง:** `gradle -p android assembleRelease` (ตั้ง `AMS_KEYSTORE_FILE` และ `AMS_KEYSTORE_PASSWORD` ถ้าต้องการเซ็น)
