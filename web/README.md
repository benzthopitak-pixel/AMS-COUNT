# โครงสร้างโค้ดหน้าเว็บ / แอป (web/)

เว็บบนคอมและแอปบนเครื่องยิงใช้ไฟล์ชุดเดียวกัน `index.html` เป็นแค่โครงหน้า ตัวโค้ดอยู่ใน `js/` และหน้าตาอยู่ใน `css/app.css`

## ไฟล์ใน js/ (เลขหน้าชื่อไฟล์ = ลำดับโหลด)

| ไฟล์ | หน้าที่ |
|---|---|
| `01-helpers.js` | ตัวช่วยทั่วไป: `$`, `LS` (localStorage), `esc`, `norm`, `ccKey`, `keyOf` / `fullCode` (Asset-Sub), `labelCC`, `capDate` |
| `02-state.js` | สถานะหน้าจอ `S`, งานที่เปิด `meta`, ทะเบียน `master` และดัชนีค้นหา (`altIx`, `subIx`, `catIx`) |
| `03-compute.js` | `compute()` รวม events เป็นผลนับปัจจุบัน · `cats()` จัดกลุ่มเรื่องที่ต้องตรวจ · ตัวเช็กสถานะ (`isOther`, `needQR`, `oldQR` ฯลฯ) |
| `04-storage.js` | คุยกับ Supabase: ส่งผลนับ (`pushEvent`, `flush`), งาน, ทะเบียน, ใครออนไลน์, `connect()` |
| `05-shell.js` | `render()` วาดหน้าใหม่ทั้งหมด · `webView()` เลือกหน้าเว็บตามเมนู · `afterRender()` |
| `06-web-reports.js` | เมนู 4.2 รายงานสรุปผล (`reportData`, `reportFile`) |
| `07-web-import.js` | เมนู 1: รายการงาน + นำเข้าไฟล์ Excel (`prepareImport`, `doImport`) |
| `08-web-live.js` | เมนู 2: ภาพรวม CC, Dashboard, หน้าแต่ละ CC |
| `09-web-inbox.js` | เรื่องรอตรวจ และเมนู 3 ปิดงาน |
| `10-stickers.js` | เมนู 5 หน้าพิมพ์สติกเกอร์ + วาดป้าย (`lblDraw`) |
| `11-label-designer.js` | เมนู 5 หน้าออกแบบป้าย |
| `12-app.js` | หน้าจอเครื่องยิงทั้งหมด + หน้าต่างแจ้งเตือน |
| `13-usb.js` | เมนู 6.1 ส่ง/รับไฟล์ผ่านสาย USB |
| `14-auth.js` | เข้าสู่ระบบ, ตั้งค่าครั้งแรก, เมนู 6.2 User, ค้นหาบนเครื่องยิง |
| `15-scan.js` | `lookup()` แปลงรหัสที่สแกน → รายการในทะเบียน · `doScan()` / `countCode()` บันทึกผลนับ |
| `16-actions.js` | ปุ่มทุกปุ่ม: ตัวจัดการ `click` อ่าน `data-a` แล้วทำงานตาม `case` |
| `17-scanner-input.js` | รับรหัสจากเครื่องยิง (Intent / คีย์บอร์ด) และปุ่มย้อนกลับของ Android |
| `18-exports.js` | ไฟล์ Excel ตามแม่แบบบริษัท (ผลตรวจนับ, AS02, ABAVN, สติกเกอร์ OGA) |
| `19-pivot.js` | เมนู 4.1 Pivot Report |
| `20-main.js` | เริ่มทำงาน (ต้องเป็นไฟล์สุดท้ายเสมอ) |

## กฎที่ต้องรู้ก่อนแก้

- **ทุกไฟล์ใช้ตัวแปรร่วมกัน** (โหลดแบบ `<script>` ธรรมดา) ฟังก์ชันในไฟล์ไหนก็เรียกกันได้ แต่ **ห้ามตั้งชื่อซ้ำ** ข้ามไฟล์ และห้ามตั้งชื่อชนกับของเบราว์เซอร์ (เช่น `print`, `close`, `open`, `top`)
- **โค้ดที่รันทันทีตอนโหลด** (ไม่อยู่ในฟังก์ชัน) ใช้ได้เฉพาะของที่อยู่ในไฟล์เลขน้อยกว่าหรือไฟล์เดียวกัน · ฟังก์ชันที่ถูกเรียกตอนกดปุ่มหรือตอนวาดหน้าใช้ได้ทุกไฟล์
- **เพิ่มไฟล์ใหม่** ต้องใส่ `<script src="js/...">` ใน `index.html` ตามลำดับ (ไฟล์ใหม่จะขึ้นเครื่องยิงเอง ไม่ต้องลง APK ใหม่)
- **หน้าจอวาดใหม่ทั้งหน้า** ทุกครั้งที่เรียก `render()` · ปุ่มใช้ `data-a="ชื่อคำสั่ง"` + `data-v="ค่า"` แล้วไปเพิ่ม `case` ใน `16-actions.js`
- **ข้อมูลผลนับเพิ่มได้อย่างเดียว** บันทึกด้วย `pushEvent({ k: 'scan' | 'edit' | 'del' | 'rv', code, ... })` แล้วสถานะคำนวณใหม่ใน `compute()`

## งานที่ทำบ่อย

| อยากแก้ | ไปที่ |
|---|---|
| ข้อความ / ปุ่มบนเครื่องยิง | `12-app.js` |
| วิธีอ่าน QR / รูปแบบรหัส | `15-scan.js` → `lookup()` |
| คอลัมน์ที่นำเข้าจาก SAP | `07-web-import.js` → `prepareImport()`, `doImport()` |
| รายงาน / ไฟล์ส่งออก | `06-web-reports.js`, `18-exports.js` |
| แม่แบบป้ายในตัว | `10-stickers.js` → `LBL_STD`, `LBL_7050` |
| สี / ขนาดตัวอักษร | `css/app.css` |

## จัดรูปแบบโค้ด

ใช้ Prettier ตามค่าใน `.prettierrc.json` (บรรทัดยาวสุด 120 ตัวอักษร):

```
npx prettier --write "web/js/*.js" web/store.js web/css/app.css
```

## ทดสอบก่อนขึ้นระบบ

```
python3 demo/build_demo.py <seed.json> AssetSync-ตัวอย่าง.html
```

ได้ไฟล์ HTML ไฟล์เดียวที่รวม js/ และ css/ ไว้แล้ว เปิดในเบราว์เซอร์ได้เลย (ไม่เชื่อมฐานข้อมูลจริง)
